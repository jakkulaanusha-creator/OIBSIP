
# NovaSpace - Landing Page

## Project Overview
NovaSpace is a modern, responsive landing page created as part of the Oasis Infobyte Web Development and Designing Internship.

## Features
- Sticky navigation bar
- Hero section with headline and call-to-action buttons
- Features section with three cards
- About section
- Contact section
- Responsive design for mobile devices
- CSS animations and gradient effects

## Technologies Used
- HTML5
- CSS3

## Project Structure
```text
WebDev-L1-LandingPage/
├── index.html
├── style.css
└── README.md
```

## How to Run
1. Download or clone this project.
2. Open `index.html` in your web browser.
3. Scroll through the page to explore the sections.
